# HCM Assistant – Keyword-Based Chatbot

A simple **rule-based chatbot** built with Python to handle common **HR and HCM-related queries** using keyword matching.

## Features

* Leave and leave balance
* Attendance and working hours
* Payroll and salary information
* Holidays
* Employee benefits and insurance
* HR and company policies
* Basic greetings and conversation handling

## Technologies

* Python
* Dictionary-based keyword matching
* `time` module

## How It Works

The chatbot compares the user's input with predefined keywords and returns the corresponding response.

```text
User Input
    ↓
Keyword Matching
    ↓
Predefined Response
```

## Limitations

* Uses exact keyword matching
* Does not use AI or an LLM
* Does not connect to a database or HCM API
* Currently runs through the command line
